## Technical Summary

The complete pre-prototype design baseline is codified in [`project_report.pdf`](project_report.pdf) and [`calculations.md`](calculations.md):
- **Problem ID:** SIH 2026 PS 26005 (MDoNER)
- **Target Application:** Decentralized farm-gate and village collection center short-term cold buffer (200 kg produce capacity).
- **Core Technology:** R290 vapor-compression refrigeration + 25 kg latent salt hydrate PCM buffer (HS10 / IP08) + 1.65 kWp Solar PV + 48 V 100 Ah LiFePO4 battery + ESP32 supervisory automation.
